# 저음 골격을 소리로 전달하는 연주 가이드

2026-11-03 최신 상태: 사용자 허용과 약관 동의를 받은 뒤 이 가이드를 업로드하고 S006의2곡 생성/신호 비교까지 완료했다. 디스크 정리 후 최신 사용자 지시로 C의 실제 폴더에서 분석을 재개했다. 저음 골격은 지지되지만 편곡·공간 차이는 남았고 청취 비교를 준비했다([비교 결과](19_HARMONIC_GUIDE_COMPARISON.md)). 아래 제안·허용 대기 설명은 당시 기록이며, 실제 실행은 CURRENT_STATUS.md와13의 S006을 우선한다.

원곡 첫 곡만을 기준으로 진행한다. 사용자 선호 후보는 G05이며 제시 구간의 G05/G06 보컬찹 존재는 사용자 확인을 받았다.

## 이 방법을 제안한 이유

S004 G05 Cover에서는 기존 저음 진행이 이어졌고, S005 오디오 없는 새 텍스트 생성에서는 Bb1/Ab1/Eb1 계열로 바뀌었다. 두 경로 모두 원곡 Gb1/Bb1 골격을 확보하지 못했다. 음악 생성 자체가 안 되는 것이 아니라 **현재 조건에서 구체적인 음정/마디 지시가 정확히 구현되지 않은 것**이다. 보컬찹은 가사 경로 변경으로 해결된 부분이므로 같은 문제로 묶지 않는다.

같은 문구로 재시도를 늘리는 대신, 측정한 저음 골격을 직접 소리로 준다. Suno가 실제 오디오를 참조하는 Cover 경로를 쓸 수 있다는 기능 근거는 있지만, 이 가이드에서 정확히 따르는지·전체 음색/그루브/편곡이 가까워지는지는 미검증이다.

## 실제로 만든 파일

- 위치: `local/deep-house/harmonic_guide_20261103/R01_harmony_guide_10bars_105bpm.wav`.
- 22.8571458초 / 105 BPM /10마디 /48 kHz stereo PCM16 /-20.00 LUFS /피크 약-12.51 dBFS, 클리핑 없음.
- 새로 합성한 오실레이터/노이즈만 사용했다. 코드 `analysis/build_harmonic_guide.py`는 원곡 녹음·Suno 생성곡을 읽지 않는다. 이 가이드는 완성곡·원곡 스템·정확한 악보가 아니다.
- 저음:0~16박 Gb1(46.2493Hz),16~30박 Bb1(58.2705),30~32박 Db1(34.6478),32~40박 Gb1 복귀. 분리 저음 진단 파일의 실제 주파수 봉우리는 각각46.33/58.23/34.61/46.33Hz 부근으로 확인했다.
- 화음 후보: Gb3/Bb3/Db4/F4→Bb3/Db4/F4→복귀. 이 보이싱·합성 음색·킥/햇·덕킹 포락선은 제작 가이드용 선택이다. 원곡의 세부 음색과 재발음/컴프레서 설정을 알아냈다는 뜻이 아니다.
- 음원·파형 검증·manifest는 로컬에 두고 커밋하지 않는다. 제작 코드와 설명만 커밋한다.

## 전송/실행 상태와 사용자 질문

가이드를 대화에서 재생할 수 있게 제시하고, **이 특정 WAV를 현재 Suno 계정에 업로드해 참조로 써도 되는지** 물었다. 사용자는 '프롬프트로 생성하는 데 무리가 있어서인가'라고 이유를 물었다. 이는 허용 답변이 아니므로 **아직 업로드0회·S006 생성0회**다. AI는 음악 생성 전체의 불가능이 아니라, 현재 결과에서 확인한 저음 재현 정밀도의 문제라고 설명했다.

컴퓨터 사용 스킬이 참조하는 `docs/confirmations.md`의 Pre-Approval Works 항목은 `[6] Upload files`, 'otherwise confirm right before the action'을 지정한다. 이 새 파일의 Suno 전송을 아직 허용받지 못한 상태에서 원곡 분석 요청·계속 진행 요청을 특정 업로드 허용으로 확대하지 않았다. 이후 사용자가 명확히 허용하면 같은 파일/목적에 중복 확인을 요구하지 않는다. 별도 권리 동의/약관이 실제 UI에 나타나면 그때 적용 규칙을 확인한다.

S006의 통합 Styles/Exclude/Lyrics와 제안 설정은13에 준비했다. 허용되면 실제 업로드/권리 확인 화면을 관찰하고, 정상 경로로 참조 설정/일반 Create1회/2곡 비교를 이어간다. 구매·구독 변경·공개 게시를 하지 않는다. 가이드가 원곡 음색을 대체하는 최종 음원이라고 설명하지 않는다.
