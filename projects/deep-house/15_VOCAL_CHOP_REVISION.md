# 보컬찹 누락 수정 — R01-S002

2026-11-03 (Asia/Seoul). 사용자 청취 답변: S001의 생성 2(G02)가 원곡에 더 가깝고, 제시한 비교 구간에서는 두 곡 모두 보컬찹이 들리지 않는다. G02는 비교용 후보이며 최종 채택이 아니다. 원곡 첫 곡이 기준이고 다른 레퍼런스 곡을 분석하지 않는다.

## 실행 전 정한 수정과 판단

- v0.1에도 보컬찹 요청이 있었지만 실제 결과에서 확보되지 않았다. 서비스 표시 Lyrics에는 [Instrumental]과 보컬찹 태그가 함께 있었다. 이 태그가 실패 원인이라는 인과 결론은 내리지 않는다.
- v0.2는 보컬찹을 첫머리의 필수 소리층으로 올리고, 알아들을 수 있는 사람의 모음성 음색·짧은 음절 어택·분리된 발음과 꼬리를 구체화한다. 긴 리드 노래를 막는 표현과 보컬 전체를 억제할 수 있는 넓은 표현을 구분한다.
- 기존 드럼/베이스, 화음층, 편곡 문단은 **문자 단위로 유지**한다. 보컬 문단 위치·우선도와 관련 제외 표현의 묶음을 바꾸는 실용 수정이다. 한 문장의 인과 효과를 검증하는 요인 실험이라고 주장하지 않는다.
- 모드/모델은 **Simple / v6-mini**를 유지한다. 가사·오디오·Voice·이미지를 별도로 첨부하지 않는다. G02를 Cover하거나 샘플로 입력하는 경로가 아니므로 G02의 실제 음색이 그대로 보존된다고 보장하지 않는다.
- 이번 수정본은 일반 Create **1회(기본 2곡)**만 실행·대조한다. 이 한 번의 결과로 성공률·최적 모델·최적 문구를 일반화하지 않는다.

## 우선 볼 결과

1. 원곡에서 사용자가 확인한 종류의 짧은 목소리 조각이 실제로 들리는가. 서비스 태그·vocals 파일명·모델 설명만으로 성공 처리하지 않는다.
2. 목소리 조각 사이에 간격과 꼬리가 있고, 긴 가사 보컬·연속 리드 노래로 바뀌지 않았는가.
3. G02가 가까웠던 전체 방향을 해칠 만큼 드럼이 밝아지거나, 배경이 현악/브라스 리드가 되거나, 그루브·공간감이 달라지지 않았는가. 사용자 미응답의 개별 요소를 이미 좋았다고 확정하지 않는다.
4. 저음 골격·편곡의 기존 차이는 계속 표시한다. 보컬찹이 생겨도 전체 재현 완료로 판정하지 않는다.

대조 앵커는 원곡 첫 곡과 S001 G02다. 새 결과는 G03/G04로 구분한다. 대조 사본은 음량만 맞추고 EQ/리버브는 적용하지 않는다. 사용자에게 새로운 분석용 프롬프트를 요구하지 않는다.

## 기능 조사와 적용 한계

[Suno 공식 Add Vocals](https://help.suno.com/en/articles/6882817)는 제공한 가사를 바탕으로 기존 인스트루멘털에 보컬을 더하는 별도 기능을 설명한다. [공식 Custom 안내](https://help.suno.com/en/articles/3197377)는 가사와 Instrumental 선택을 구분한다. 이 문서들이 **가사 칸을 비운 채 정확한 보컬찹을 생성하는 공식 보장법**을 제공하는 것은 아니다. 이번에는 사용자의 가사 비움 방식을 유지하며 새 가사나 별도 보컬 합성을 자동으로 추가하지 않는다. 최신 기능·기존 모델의 커뮤니티 체험을 섞어 확정 규칙을 만들지 않는다.

입력 전문과 필요한 설정은 `13_FIRST_TRACK_PROMPT_LOG.md`의 R01-S002 v0.2에 통합해서 기록한다. 생성 결과·실제 설정·측정·사용자 청취는 실행 후 이 문서에 덧붙인다.
