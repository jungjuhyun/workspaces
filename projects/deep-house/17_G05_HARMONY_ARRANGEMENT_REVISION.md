# G05 이후 저음·편곡 수정

2026-11-03. 사용자는 G05/G06의 제시 구간에 모두 보컬찹이 들리며 G05가 더 가깝다고 답했다. G05는 현재 후보로 보존한다. 원곡 첫 곡만이 최종 기준이다.

## 수정 전에 확인한 차이

- 원곡: 약 105 BPM, 대표 8마디 Gb1→Bb1 장기 유지와 짧은 Db1 연결. 상층 Bb/Db/F, Gbmaj7/Bbm 색채는 유력 후보다.
- G05: 약 105 BPM은 가깝지만 C2/Db2/Bb1/F1/Eb2 등의 저음 움직임을 이어받았다. 보컬찹 존재가 해결됐다고 이 차이를 통과시키지 않는다.
- 60~178초 안의 8초 평균 드럼 최저 창: 원곡 150~158초, G05 138.25~146.25초. 음원 길이도 222초 대 184.8초다. 최저 창이 전체 비움의 정확한 경계라는 뜻은 아니다.

## 이번 구현

G05 참조 Cover에서 저음 교대·상층 음 구성·비움/복귀를 명시한 입력으로 바꾼다. 보컬 입력 Ah/Oh와 짧은 발음·간격·꼬리 의도는 유지한다. Duration Custom 222초를 실제 선택하고 Audio Influence는 80에서 50으로 내려 기존 진행 수정 여지를 주려 한다. 효과는 결과에서 확인해야 한다. 전체 통합 입력과 실제 UI 확인은 13의 S004 v0.4에 둔다.

새 결과 G07/G08을 생성하면 먼저 보컬 신호가 유지되는지, 저음 골격이 실제로 바뀌었는지, 비움과 길이가 원곡 방향으로 이동했는지 확인한다. 이미 확인한 보컬 존재를 매번 사용자에게 다시 묻지 않는다. 음악적 차이를 EQ/리버브로 해결했다고 쓰지 않는다. 이 한 번의 Cover 수정에서 저음이 다시 그대로 남으면 같은 요청을 반복해 크레딧을 소모하지 않고 경로 한계를 기록한다.

현재는 실행 전 계획이며 생성 결과는 아래에 구별해 덧붙인다.

## S004 실제 결과 — 목표 미달

G07/G08을 Create 1회로 만들고 WAV 다운로드·분리/신호 대조했다. 10크레딧 사용, 남은 12,032. Duration222 입력 후 실제 파일은 221.640/221.560초로 나왔으나 길이 접근을 편곡 접근으로 바꾸지 않는다. 보컬 배정 신호 RMS 최고는 약 -19.48/-18.57 dBFS로 유지된다. 새 두 곡의 사용자 청취 확인은 아직 없다.

두 곡 모두 60~108초에서 C2→Db2/Bb1→F1→C2 등의 G05 후보 순서를 계속 따른다. 원곡의 Gb1/Bb1 골격으로 바뀌지 않았다. 60~178초 범위의 8초 드럼 최저 창도 G07 138.5~146.5, G08 130.25~138.25초로 원곡150~158초와 다르다. 같은 Cover 수정 반복은 종료한다. G05를 비교 후보로 계속 보존한다.

실제 입력은 딥하우스/화음 명세였지만 Copy styles에는 `harmony g flat Psychedelic Trance, Full-On gb bb db f`라는 의도하지 않은 표시가 생겼다. 원문과 렌더를 13에 모두 기록했다. 곡이 실제 트랜스라는 청취 결론이나 이 표시가 저음 실패 원인이라는 인과 결론은 아니다.

후속 S005는 Cover 오디오를 없앤 새 Advanced 생성으로, 보컬 입력을 유지하며 화음을 풀어 쓴다. 이제 다른 저음 진행을 생성할 수 있는지 확인한다. 기존 G05의 음색을 그대로 보존하는 경로라고 가정하지 않는다. 정확한 전체 입력/제한은 13에 둔다.

## S005 실제 결과 — 새 텍스트 생성도 목표 저음 미달

오디오 조건 없이 Advanced/v6-mini, 동일 Ah/Oh Lyrics와 명시적 두 화음 지시로 Create1회, G09/G10 두 곡을 생성했다. 10크레딧 사용, 남은12,022, 새 제작 누적50. 길이는147.200/221.560초다. 입력 Duration222가 모든 결과의 길이를 보장하지 않았다.

보컬 배정 출력 최고 .25초 RMS는 -20.05/-20.20 dBFS로 나타났지만 사용자 청취 확인은 아직 없다. 약105 BPM 부근의 박동 추정(104.53/104.36)을 유지한다. 저음은36~120초의 여러4초 셀에서 Bb1→Ab1→Eb1 계열로 바뀌며 원곡 Gb1/Bb1 장기 교대가 아니다. 전체 조성이 틀렸다고 단정하는 것과 특정 베이스 진행이 다르다는 관찰을 구분한다.

G10 원본64.25~64.75초에서 약38.6/77.5/116.3/154.9 Hz 계열이 나타나 분리 Eb1 후보와 양립한다. G09 원본에서는 킥/기본음/배음이 더 섞이므로 가장 큰 피크 하나를 저음 기본음으로 확정하지 않았다. .5초 Hann 창의 물리적 분해능 약2 Hz와 제로패딩 좌표를 구별했다. 로컬 `raw_mix_bass_spectra.json`에 원자료를 보존했다.

60초 이후8초 평균 드럼 최저 창은 G09 135.5~143.5(끝부분 포함), G10 115.5~123.5초다. 원곡150~158초의 비움과 일치한 편곡이라고 쓰지 않는다. G09는 원곡 주요 비움 시각보다 먼저 끝난다. 자동 선택 본문 창 G09 55.25~87.25초, G10은 로컬 JSON에 기록된 창이며 같은 편곡 상태라고 가정하지 않는다.

현재 결론은 **이 조건의 텍스트/참조 수정에서 지정 저음 골격을 얻지 못했다**는 것이다. 모든 Suno 모델·모든 프롬프트에서 불가능하다는 일반 규칙이 아니다. G05를 사용자 선호 후보로 보존하고 같은 문구의 추가 재생성은 중단한다. 다음 제안은18의 새로 연주한 오디오 가이드다. 새 결과의 음색/그루브를 AI가 직접 들었다고 주장하지 않는다.
