# G02 참조와 비언어 음절로 보컬찹 생성 경로 변경

2026-11-03. 원곡 첫 곡이 최종 기준, 사용자 선호 S001 G02가 현재 생성물 비교 앵커다.

## 경로를 바꾼 근거

- S001: 사용자가 G02를 더 가깝다고 선택했고, 두 비교 구간 모두 보컬찹이 들리지 않는다고 답했다.
- S002: 보컬을 필수 층으로 첫머리에 강조해 같은 Simple/v6-mini에서 1회 2곡을 더 만들었다. G03/G04 모두 서비스 표시 Lyrics는 [Instrumental]이고, htdemucs_6s의 vocals 출력도 매우 작았다. 이 문구 묶음의 강조만으로 보컬찹을 확보했다고 볼 근거가 없다. 단어를 계속 추가하는 재생성은 종료한다.
- 공식 [Add Vocals 설명](https://help.suno.com/en/articles/6882817)은 제공한 가사를 사용하는 별도 기능을 설명한다. 실제 G02의 Remix 메뉴는 Cover/Reuse Prompt/Mashup/Sample this song/Use as Inspiration/Voice, Edit 메뉴는 Extend/Crop/Remove Section/Reverse/Adjust Speed/Find a Collaborator/Fade In/Fade Out/Replace Section/Get Stems/Remaster/Open in Studio/Open in Editor였다. **Add Vocals는 이 메뉴들에서 관찰되지 않았다.** 따라서 그 기능을 실행했다고 쓰거나 보이지 않는 API를 호출하지 않는다.
- 실제 제공되는 **Cover**를 사용해 G02를 참조하고 짧은 Ah/Oh 발음을 Lyrics에 직접 전달한다. 사용자에게 문장 가사·모델 선택·새 분석 프롬프트 작성을 맡기지 않는다. 평소 Lyrics를 비우던 방식을 이번 경우 변경한 것은 AI의 작업 선택으로 명시한다.

## 실행 전 비교와 제한

- 통합 전문/설정: 13의 R01-S003 v0.3. 원래 G02 파일과 곡은 보존한다. 타인의 음원·원곡 MP3를 서비스에 업로드하지 않는다.

- 보컬의 실제 존재, 짧게 잘린 발음인지 긴 리드인지, G02의 그루브·음색·공간 방향 유지 여부를 대조한다. 보컬찹이 생겨도 원곡 전체 재현 완료를 선언하지 않는다.
- Audio Influence 80은 현재 기본값 25보다 참조를 따르게 하려는 제안값이다. 원래 악기 보존·동일 파형·최적값을 보장하지 않는다. 기존 PDF의 Cover 90/20을 일반 규칙으로 채택하지 않는다.
- 생성 결과는 G05/G06으로 구분하고 신호/분리 측정과 사용자 청취를 구별한다. EQ/리버브는 이 단계에서 추가하지 않는다.

### G02의 반주와 원곡 기준을 구별한 대조

- 약 105 BPM과 60~108초의 4초 셀 우세 저음 후보 순서(C2→Db2/Bb1→F1 등의 반복)는 G02와 두 Cover에서 대체로 유지된다. 그러나 원곡의 Gb1/Bb1 장기 교대가 아니라 **기존 생성물의 차이도 이어받은 것**이다. 보컬 생성 경로가 작동했다고 전체 재현이 해결된 것은 아니다.
- G02와 같은 시각의 분리 bass/drums/other 파형을 단순 상관으로 비교했지만, 지연·위상·곡 구조를 맞추지 않은 값은 청감 유사성이나 완전 보존 여부의 판정에 쓰지 않았다. 비교 원자료는 로컬 JSON에 보존했다. 오디오 참조 80을 '반주 원본에 보컬만 얹기'로 설명하지 않는다.
- 자동 본문 창은 G05 92.75~124.75, G06 111.25~143.25초다. 둘 다 동일 활동 문턱의 연속 32초 구간이 없어 평균 활동 최대 창으로 선택했다. 선택 창 중역 S/M은 각각 약 -8.17/-6.51 dB, 저역 약 -20.10/-20.00 dB지만 원곡 선택 창과 같은 편곡·보컬 상태가 아니다. 수치 근접을 청감 순위로 바꾸지 않는다.
- G05 후반 168~184.8초의 onset 추정은 약 52.2 BPM으로 반박/감산 영향이 섞일 수 있다. 전체 곡 템포가 52 BPM으로 변했다고 확정하지 않는다. 짧아진 파일의 분석 창은 실제 끝에서 잘라 기록했다.
