# 문서 레드팀 검토 보고서

문서·운영 판정 버전: 0.4.2 / 음악·요구 의미 기준선: 0.4 / 2026-10-27 (Asia/Seoul)

## 1. 결론과 검토 범위

검토 전 문서 묶음 0.4.1을 대상으로, 사용자 목표에 어긋나는 채택·진행 정지·과도한 판정·인계 오류가 가능한지 17개 반례를 대입했다. 8개는 명시적 불일치 또는 보완할 분기/통제의 누락, 9개는 기존 규칙이 이미 막는 경로로 분류했다.

이는 **단일 작성자의 적대적 문서 검토와 규칙의 구조 검사**다. 별도 AI/외부 팀을 실제 실행한 공격 실험, 실제 생성 결과의 테스트, 보안 침해의 성공 사례가 아니다. “보완 대상”은 문서에서 가능한 오독·모순·통제 미명시를 뜻하며 실제 AI가 그 행동을 했다는 뜻이 아니다.

음악 목표·R01~R22·T/G 표의 의미는 유지했다. 적용 범위와 진행 경로의 실제 수정이 있으므로 운영 판정은 0.4.2로 개정했다. 이번 발견은 기존 요구를 충족하지 못한 FIX이며 사용자 요구가 바뀐 탓으로 처리하지 않는다.

## 2. 공격 목표와 판정 기준

보호할 결과: 원하는 청감을 해치지 않는 자료/설계, 근거 수준의 정확한 보고, 필요한 작업의 진행, 사용자 재설명 최소화, 같은 프로젝트의 최신 파일로 재개.

반례는 다음 경계를 공격했다.
- 근거의 등급을 효과 검증으로 바꾸거나 필수 조건을 우회하는 채택.
- 단일 곡/곡 간 구별/장시간/개별 채택/기본값 검증을 서로 대신하는 판정.
- 뒤 단계의 검증을 앞 단계 조건으로 요구하는 진행 정지.
- 상태 질문·외부 자료 지시·동명 파일이 현재 작업 범위를 바꾸는 인계.

기존 규칙이 이미 금지하는 행동은 새 결함으로 세지 않았다. 명시적 모순과 명세의 불명확성, 실행 환경의 상위 규칙이 막을 수 있지만 이식 문서에 빠진 경계를 구분했다. 심각도는 이 프로젝트의 재작업·잘못된 채택·진행 정지 위험에 대한 검토자의 판단이며 통계 점수나 보안 등급이 아니다.

## 6. 재검토와 기계 검사 구분

수정 후 각 반례에 관련된 문구·적용 범위·다음 행동을 다시 대조했다. 구조 검사는 다음 이미 발견한 결함의 재등장 여부를 확인한다.

1. 우선순위의 정본 원장 범위에 R22가 포함되는가.
2. D05의 단일 청감과 T06의 곡 간 비교가 분리되는가.
3. P2에서 D04를 선행 의무로 요구하지 않고 미해결 효과를 검증 계획으로 넘길 수 있는가.
4. 사례 근거 후보와 명시적 탐색 후보의 분기가 있는가.
5. 중간 상태 질문이 기존 유효 작업 허용을 자동 취소하지 않는가.
6. 외부 자료 안의 지시를 작업 지시로 실행하지 않는 경계가 있는가.
7. 실제 반환된 파일 ID·프로젝트 식별자로 동명 정본을 구별하는가.
8. 단일 출력 채택과 D07 검증된 기본값이 분리되는가.

이 검사는 문구와 필드의 구조적 불변 조건을 검사하며 AI의 의미 이해·실제 수행을 자동 검증하는 도구가 아니다. 수정 전 실패는 해당 문서 조건의 부재/충돌이지 실제 공격 성공률이 아니다.

기존 차단 9개도 유지하는지 재대조한다. R요구 22개의 의미·ID, T표 8개와 G표 10개의 내용, 기준 음원/직접 확인 부족의 보류, 미해결을 READY로 승격하지 않는 규칙, 실제 조사·청취·생성 0건 상태를 확인한다.

## 7. 남은 한계와 다음 작업 범위

- 독립 모델 또는 새 AI 세션을 실행해 행동을 관찰하지 않았다. 문구 보완 후 모든 AI가 항상 따를 것이라고 보장하지 않는다.
- 기준 원본·현재 모델·승인 음원은 여전히 미확인이다. 실제 생성의 재현성·다양성·장시간 편안함은 검증하지 않았다.
- 외부 자료 지시 경계·정본 ID는 이식 문서의 보완이며 계정·실행 환경의 별도 접근 통제를 대체하지 않는다.
- 실제 조사를 진행할 때 새 자료가 현재 결론과 충돌하면 그 근거와 영향받는 판단만 재검토한다. 단순히 재검수한다는 이유로 새 취향을 평가 기준에 추가하지 않는다.
- 현재 허용 범위는 문서 레드팀·필요한 문서 보완·보존이다. 실제 음악 자료 수집과 Suno 생성은 시작하지 않았다.

## 8. 최종 상태

발견한 8개 문서상 문제의 보완을 반영했다. 검토한 반례의 문서상 차단·진행 경로를 명료화한 것이며, “모든 공격 차단”, “독립 인계 성공”, “음악 재현 검증 완료”로 보고하지 않는다.
