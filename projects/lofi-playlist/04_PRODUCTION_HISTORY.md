이 대화 이전의 20개 프롬프트는 미검증 시안이며 본 체계에서 승인·생성된 20곡이 아니다. 사용자는 아직 해당 시안으로 생성하지 않았다고 설명했다. 기존 전체 음악 보유 이력은 확보하지 않았으므로 “사용자에게 기존 곡이 없다”는 뜻도 아니다.

## 식별 및 상태

플레이리스트 PL-0001 / 곡 설계 TRK-000001 / 생성 시도 GEN-000001.
수정 버전은 같은 설계 ID 아래 별도로 기록한다. 모델이 한 번에 여러 출력을 주면 출력별 ID를 붙인다. 실패·폐기·보류 이력을 지우지 않는다.

상태: 설계 중 → 설계 검토 완료 → 프롬프트 준비 → 생성 → 평가 → 채택/수정/보류/폐기.

## 중복 점검 절차

1. 같은 플레이리스트의 전체 설계와 인접 곡을 비교한다.
2. 누적 이력에서 비슷한 편성·첫 사건·선율 음형·그루브·화성 구조·베이스·전개를 가진 후보를 찾는다.
3. 키만 바뀐 코드 기능, 악기만 바뀐 같은 연주·도입, BPM만 바뀐 같은 패턴을 따로 검토한다.
4. 공통 요소가 있다는 이유만으로 폐기하지 않는다. 여러 음악적 특징이 겹쳐 곡의 구별이 약해지는지를 설명하고 수정한다.
5. 실제 오디오가 생기면 입력 설계와 별도로 청취 비교한다. 프롬프트가 달라도 결과가 비슷할 수 있고, 같은 조건에서도 결과가 다를 수 있다.
6. 비슷한 곡과 차별 요소, 남는 불확실성을 기록한다. 근거 없는 숫자 점수나 “완전한 비중복” 보장을 만들지 않는다.

이력을 조회하지 못한 제작분은 비교 누락 범위를 표시한다. 수백 편의 분량을 문장 조합 개수만으로 확보했다고 주장하지 않는다.
## 0.2 제작 판정 필드와 통과 조건

각 설계·생성 시도에 기준 버전 / 적용 T조건·D결정 / 사용한 CORE·SUPPORT·LEAD 근거 ID / 설계 통과·실제 청감 통과·사용자 채택을 분리한 상태 / 미판정 이유 / 잠긴 결정 / 가장 유사한 후보와 구체 차이 / 다음 조치를 추가한다.

D06 설계 불합격: 차이가 악기명·키·BPM뿐임, 시작만 다르고 이후 연주 구조는 같음, 문구만 다름, 공통 청감을 희생한 대비.
D06 통과에 필요한 것: 주된 음형·그루브·화성 움직임·베이스·악기 간 상호작용 중 지속되는 차이를 구체적으로 설명하고, 도입과 가장 유사한 누적 곡을 함께 비교한 기록. 실제 음원 차이를 보장하지 않는다.
D05 청감 합격: 사용자 승인 기준 음원·구간, 실제 출력 직접 확인, T조건 비교 기록과 명시적 금지 위반 없음. 청취 불가·기준 미확보는 미판정이며 문구 평가로 대신 통과시키지 않는다.
0.4.2 당시에는 설계·생성·청감 합격·사용자 채택 모두0건이었다. 최신 실제 설계 건수/상태는 위 집계와 아래 PL-0001을 따른다.
## 0.3 요구와 기준 변경 추적

각 플레이리스트·곡 설계에는 관련 R요구 ID와 적용 기준 버전을 남긴다. 수정은 기존 요구 누락(FIX), 새 사용자 지시(NEW_REQUEST), 새 근거(NEW_EVIDENCE), 선택적 개선(OPTIONAL)을 구분한다. 재검수에서 새 취향을 추가해 기존 합격을 소급 취소하지 않되 실제 누락·오류는 수정한다.
## 0.4 건반의 반복 청취 적합성 — R22/U11/T08

설계에는 건반의 주요/보조 역할, 실제 음역 또는 설계상 음역(구분), 선명도·발음, 전면 배치, 반복 음형·빈도·쉼을 기록한다. 플레이리스트에는 연속되는 곡들의 유사 건반 음역·어택·울림·음형과 누적 노출을 비교한다.

평가에는 직접 확인한 파일·구간·재생 순서·누적 확인 시간·재생 조건·평가자, 거슬림/피로 보고의 내용, 짧은 확인/목표 길이 확인/미확인 상태를 남긴다. 분석 도구의 지표와 사람의 청취 보고를 구분한다. 1시간 목표에서 일부 구간만 확인했으면 장시간 적합은 미판정으로 남긴다.

문제가 있으면 음역·보이싱·음색·발음·배치·반복 밀도·쉼·곡 순서 중 원인에 해당하는 요소를 수정하고 새 시도의 평가 범위를 기록한다. 음량만 내리거나 다른 악기로 같은 밝은 울림을 반복한다고 개선 완료로 선언하지 않는다. 현재 실제 청취 평가는 0건이다.
## 레드팀 보완 — 판정과 채택의 적용 단위

D05(해당 출력·구간의 청감), D06(설계·곡 간 구별), 장시간 확인 범위, 개별 출력 채택, D07(검증된 기본값)을 따로 기록한다. 첫 한 곡의 청감 판정에 T06의 비교곡 존재를 강제하지 않는다.
