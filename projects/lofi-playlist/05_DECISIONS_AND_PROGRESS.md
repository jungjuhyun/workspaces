## 다음 작업

문서 검토·구조 정리는 완료했으며 실제 조사·생성은 미착수다. 다음 행동은 최신 사용자 지시의 범위를 먼저 확인한다. 조사 착수가 허용된 경우에 한해 아래 순서를 적용한다. 입력 부족의 분기 조건은 02 §5가 정본이다. 실제 조사 착수 시 기존 자료에서 원본·설정·승인 음원 확보를 먼저 시도한 뒤 P1/Q01을 진행한다. 기준 음원 미확보는 선행 조사를 막지 않지만 D05/D07의 최종 채택을 잠근다.

1. 기존 관련 자료에서 원본 Style·Exclude·실제 설정·사용자 승인 음원과 구간을 확보하려 시도하고 미확보 항목을 기록한다. 이는 외부 웹 자료 수집이나 생성 실험과 구분한다.
2. 현재 모델·접근 조건을 조사하고 SEARCH·SRC·CLM 및 E/D 판정 기록을 남긴다.
3. 생성 방식과 입력·옵션을 이어서 확인한다.
4. 계정에서만 확인 가능한 미확인 조건을 좁힌다. 공개 자료로 알 수 있는 내용을 처음부터 사용자에게 떠넘기지 않는다.
5. 질문별 READY/N/A/UNRESOLVED와 가능/잠긴 결정을 기록하고 다음 단계로 진행한다.

현재 작업에는 위 1~5의 실제 수집 결과가 없다.
