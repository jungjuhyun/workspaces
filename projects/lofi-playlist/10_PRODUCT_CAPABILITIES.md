## 이번 프로젝트의 모델 우선순위 — 사용자 경험 반영

2026-10-27 사용자는 직접 테스트한 결과 v6mini가 v6pro·v6wild보다 가장 잘 나왔다고 보고했다(SRC-0041/CASE-0001). 이는 이 프로젝트의 모델 선택에 사용할 실제 사용자 경험이며, 후속 조사·비교에서 v6-mini를 우선 다룬다.

이 보고의 모델 표기는 그대로 보존한다. v6pro라는 사용자 표기를 공식 목록의 v6와 임의로 동일시하지 않는다. 입력/설정·시도 수·출력·세부 평가 항목은 아직 미공개이고 AI 직접 비교는 하지 않았다. 따라서 mini의 전반적 우위·원본 생성 모델·검증된 제작 기본값을 확정하는 결론은 아니다.

아래 '공식 포지셔닝'은 제품 설명이며 목표 음악의 품질 순위가 아니다. 유료 접근 여부나 flagship/mini 명칭을 목표 적합성의 순위로 사용하지 않는다. 문서는 공식 기능과 확인 수준을 구분한 조사 자료로 사용할 수 있으며, 최적 모델/설정의 실증 보고서로 사용하지 않는다. 재검토 근거는03 RECHECK-0002다.

## 1. 이번에 확인한 것과 아직 결정할 수 없는 것

- 현재 공식 모델 명칭은 v6, v6-wild, v6-mini다. Pro는 요금제 명칭이며, v6-pro라는 별도 모델은 이번 공식 목록에서 확인되지 않았다. 사용자 예시 v6pro를 v6와 임의로 동일시하지 않는다.
- 모델/방식/입력/제어/참조를 분리한 목록을 아래에 기록했다. 모델 이름만 바꾼 프롬프트를 완성된 제작 체계로 취급하지 않는다.
- Variety는 Style 문구를 조정하는 기능이며 Weirdness와 다르다. My Taste의 Style 보강도 별도로 기록해야 한다.
- 입력 한도는 위 사용자 보고의 Simple3,000/고급Style1,000을 확보했다. Lyrics/Exclude·대부분의 슬라이더/계정값·Duration 범위·일부 호환은 미확인이다.
- 확인 가능한 연결에 Suno 계정 탭이 없어 사용자 화면을 직접 검사하지 못했다. 다른 브라우저/로그인/계정을 추정해 사용하지 않았다. 현재 가격표·공식 문서의 공개 조건을 사용자 실제 조건으로 보고하지 않는다.
- 이번 산출물은 제출 가능한 공개 사실 조사 기록이다. P1 전체가 READY이거나 현재 설정 프리셋이 확정됐다는 결론은 아니다.

용어: '확인'은 해당 공식 문서에 명시된 사실/정책을 뜻한다. 품질·정밀함·일관성 등의 표현은 제조사의 제품 설명이며 이 작업의 검증 결과가 아니다. 한국어 설명은 번역이고 실제 계정의 한국어 UI 명칭은 미확인이다. 출처 전문/확인 범위/제한의 정본은 03_EVIDENCE_REGISTER.md의 SRC-0009~0040 및 재확인 SRC-0006이다.

근거: SRC-0016~0018/0009/0030/0036 및 SRC-0006.

Variety와 My Taste/Style 보강은 입력이 달라질 수 있는 별도 경로다. 앞으로는 '작성한 Style', '보강/수정한 뒤 실제 제출한 Style', '결과 화면에 표시된 Style'을 구분해 보존한다. 이 세 표현의 일치/차이가 실제 소리에 미친 효과는 따로 평가한다. 마법봉을 쓰지 않았는데 모든 Style이 My Taste 때문에 자동 변경된다는 결론도 내리지 않는다.

웹 검색에서 Style/Exclude 1000자, Lyrics 5000자 등을 주장하는 비공식 자료가 나왔지만 현재 공식 한도나 사용자 계정 관찰로 채택하지 않았다. 서로 다른 제3자 API의 제한을 Suno 웹 한도로 옮기지 않는다. 검색 미확보는 한도 부재의 증명이 아니다.

반복 제작 운영에 영향을 주는 별도 제약: 생성 크레딧과 다운로드 한도는 다르다. 현재 공개 안내는 Pro20곡/월, Premier60곡/월이며 Premier Studio 이용에 대한 무제한 예외도 있다. 무료 체험 다운로드는 가입 시점 등에 따른 조건이 있어 모든 무료 계정이 새로7회 받는다고 쓰지 않는다. 사용자 잔여량·내보내기 경로·추가 비용은 미확인이다(SRC-0014/0037/0039). 첫20곡과 이후 여러 플레이리스트의 생성 가능 수를 곧바로 내보낼 수 있는 수로 계산하지 않는다. 요금제 변경·구매 권고는 하지 않았다.

P1을 전부 완료한 것으로 표시하지 않는다. 이 문서의 공개 사실 조사/기록은 완료했고, 미확인 하위 조건은 영향받는 결정과 함께 남긴다. 추적 가능한 실제 자료/화면이 들어오면 해당 항목만 갱신한다.

다음 조치는 두 갈래다. 계정 화면으로만 확인 가능한 공백은 화면이 연결될 때 조사하고, 그 공백에 의존하지 않는 v6 계열 실사용 사례 탐색은 사용자 경험에 따라 v6-mini를 우선 다루고 나머지 모델과 비교하도록 진행할 수 있다. P2의 효과 주장을 READY로 전제하거나 P1/P2 전체 통과 이벤트를 임의로 기록하지 않는다. 실제 생성은 현재 허용 범위에 포함되지 않는다.
